SUBAGENT DEEPSEEK / LOCAL SETTINGS

配置你的 DeepSeek 协作助手

主 Agent 规划与审阅，DeepSeek 执行。填写路径，检查配置，再下载到安装目录。

01 · 运行环境

这里只配置 DeepSeek 及其连接。页面不读取密钥、不联网、不保存浏览器记录。
请填写真实的 Linux 绝对路径。浏览器无法确认文件是否存在；安装后的运行时会再次检查。凭据文件应属于当前用户，权限为 600。

02 · DeepSeek 执行设置

默认读取 Codex 已信任项目，无需逐个填写目录或安装 Hook。撤销信任后同步拒绝；执行权限仍按当前父 Agent 授权。
完全访问会给予独立执行任务更广的访问权限。请确认符合你对该任务的授权。
高级集成设置 · 一般无需修改
仅用于检查任务起始目录，并非完整的文件系统沙箱；实际执行限制由运行时提供。

03 · DeepSeek 网页连接（三层协调必需）

三层协调需要此连接；独立 worker 可关闭。不会自动安装或启动 Harness。

生成 Harness 启动脚本此路径只用于生成脚本，不写入 settings.json。需要已安装 Node / pnpm 和 Harness 依赖。
下载后运行 bash 网页启动-配置生成.sh，保持终端打开；Ctrl+C 停止。脚本沿用上方地址、端口及启动日志，日志只允许当前用户访问。若服务已启动，脚本会拒绝重复启动，不会结束现有进程。若已有自己的启动器，也可运行：bash /你的路径/网页启动.sh start。确认它写入上方相同的启动日志。
网页任务的权限按每次传入的父 Agent 模式同步。“帮我审批”和完全访问映射为 Harness 完全访问；这里的独立任务权限不控制网页任务。
